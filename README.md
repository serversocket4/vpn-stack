# VPN Stack

Исходники собственной VPN-инфраструктуры: веб-админка, Telegram-бот, подписки и мониторинг. Российский вход пересылает пакеты на сервер выхода в Нидерландах. Пользователи получают одну HTTPS-подписку с несколькими каналами.

Это обезличенная версия исходников. В ней нет рабочих пользователей, ключей, токенов бота, ссылок подписок, сертификатов, журналов или базы админки. При подготовке установки создаются новые секреты.

## Возможности

- Вкладка VPN: список пользователей, доступ, маршрут, условия и трафик; создание, пауза, возобновление и отключение доступа.
- Три профиля маршрутизации: «ИИ и соцсети», весь трафик и весь трафик кроме российских сайтов; дополнительные доменные правила.
- Страница приглашения: инструкция установки клиента, импорт подписки и QR-код.
- Telegram-бот: `/vpn`, `/stats`, `/relay`, `/relayhelp`, `/link`, `/password`, `/logout_all` и подтверждение действий из админки.
- Дашборд: ресурсы RU/NL, четыре VPN-канала, Telegram-прокси, межсерверная связь, события и трафик пользователей.
- История за 1/6 часов, сутки, 7 и 30 дней; выбор частоты обновления экрана, включая 1 секунду.
- Настраиваемые Telegram-уведомления о сбое, восстановлении и продолжительном росте задержки.
- Отдельная служебная учётная запись `monitoring` для проверок без добавления тестового трафика обычным пользователям.

## Схема

```text
Happ / совместимый клиент
        │
        ▼
RU: nftables, пересылка TCP/UDP
        │
        ▼
NL: Xray + Hysteria2 + Telemt → интернет
    Caddy → подписки и веб-админка
    Telegram-бот + мониторинг
```

RU работает как транспортный посредник. VPN-аутентификация и пользовательские профили находятся на NL. Маршрутизацию приложений применяет клиент; российские сайты, указанные как прямые, могут обходить VPN.

| Канал | Протокол | Вход RU по умолчанию | Служба NL |
| --- | --- | --- | --- |
| Основной | Hysteria2 с hopping | UDP 443 и 20000–40000 | UDP 443 |
| Запасной 1 | VLESS TCP/TLS | TCP 2083 | TCP 2083 |
| Запасной 2 | Hysteria2 | UDP 443 | UDP 443 |
| Запасной 3 | VLESS XHTTP/REALITY | TCP 18443 | TCP 8443 |
| Telegram-прокси | MTProto | TCP 8880 | TCP 8880 |

Порты в примерах необходимо проверить на своих серверах и согласовать с firewall. В частности, публичный и внутренний порты XHTTP различаются.

## Подготовка своей установки

Нужны два VPS с Linux/systemd, Python 3.10+, совместимые Xray, Hysteria2, Telemt и Caddy, собственный Telegram-бот и действующий TLS-сертификат для публичного IP NL. Внешние программы и сертификаты не включены в репозиторий. Базовый целевой вариант — Ubuntu 24.04 на выделенных для проекта VPS.

```sh
git clone https://github.com/OWNER/vpn-stack.git
cd vpn-stack
umask 077
cp examples/installation.json /root/vpn-stack-settings.json
# Заполните приватный файл своими параметрами.
python3 scripts/prepare.py \
  --settings /root/vpn-stack-settings.json \
  --output /root/vpn-stack-runtime \
  --site-cert /защищённый/путь/site.crt \
  --site-key /защищённый/путь/site.key
python3 scripts/install.py --runtime /root/vpn-stack-runtime --dry-run
```

Сначала прочитайте [установку](docs/INSTALLATION.md). Генерация создаёт конфигурации и новые доступы, а установка копирует файлы в свежие пути. Она не скачивает VPN-ядра и не запускает службы автоматически. Настройка RU, SSH-доступа, firewall, TLS и первый запуск выполняются отдельно.

## Что проверено и что требуется проверить

Это экспорт исходников с шаблонами подготовки, а не обещание готовой установки одной командой. Установку всего опубликованного комплекта с нуля на двух чистых VPS ещё нужно проверить целиком. Успешная проверка синтаксиса не подтверждает работоспособность сети.

Серверная проверка VPN проходит по пути **NL → RU → NL → интернет**. Она не измеряет участок от телефона или компьютера до RU. Частота обновления страницы не меняет частоту получения новых измерений: сетевой сборщик работает раз в минуту.

Подписки ориентированы на Happ. Поддержку Hysteria2, obfuscation, XHTTP, hopping и правил маршрутизации в другом клиенте проверяйте отдельно.
